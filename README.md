# 🎓 Smart Campus Management System

## 📌 Project Overview
The Smart Campus Management System is a Python-based application designed to simplify and automate basic college management activities. It provides a single platform to manage student details, attendance, academic marks, library books, and fee records.

## 🎯 Objectives
- Simplify student record management.
- Maintain attendance records.
- Calculate student grades automatically.
- Manage library books efficiently.
- Maintain fee payment records.

## ✨ Features

### 1. Student Management
- Student registration
- View student details
- Search student records
- Delete student records

### 2. Attendance Management
- Mark students as present or absent.
- Generate attendance reports.
- Calculate attendance percentage.

### 3. Academic Management
- Add subject marks.
- Calculate total marks.
- Calculate average marks.
- Generate grades automatically.

### 4. Library Management
- Add new books.
- Display available books.
- Issue books.
- Return books.

### 5. Fee Management
- Record student fee payments.
- Generate fee reports.
- Calculate total paid fees.

## ⚙️ Installation and Execution

**Step 1:** Install Python 3.

**Step 2:** Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 3:** Open the project folder.

```bash
cd Smart-Campus-Management
```

**Step 4:** Run the application.

```bash
python smart_campus.py
```

The application automatically creates the JSON database when it starts.
